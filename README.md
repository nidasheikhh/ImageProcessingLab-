## 📌 About the Project

The Image Processing Lab Website is an interactive educational platform developed to demonstrate different Digital Image Processing techniques.

The website provides a simple and user-friendly interface where users can upload images, apply different image processing operations and observe the processed output.

The project contains **11 practicals**, covering fundamental image processing concepts such as image operations, geometric transformations, image enhancement, filtering, inpainting, compression, morphology, object detection, edge detection and colour space conversion.

## 🎯 Objectives

- To demonstrate important Digital Image Processing techniques.
- To provide an interactive platform for Image Processing Lab practicals.
- To understand the effect of different operations on digital images.
- To provide visual comparison between original and processed images.
- To make Image Processing concepts easier and more interactive for students.

## 🧪 Practicals Included

| No. | Practical | Description |
|-----|-----------|-------------|
| 1 | Basic Image Operations | Grayscale, brightness and bitwise operations |
| 2 | Geometric Transformations | Translation, rotation, scaling, shearing and reflection |
| 3 | Image Enhancement | Histogram equalization, smoothing, sharpening and thresholding |
| 4 | Contrast Enhancement | Contrast, brightness, smoothing and sharpening |
| 5 | Spatial Filtering | Averaging, Gaussian, median and bilateral filtering |
| 6 | Image Inpainting | Telea and Navier-Stokes based inpainting |
| 7 | Image Compression | Image compression and size comparison |
| 8 | Morphological Operations | Erosion, dilation, opening and closing |
| 9 | Object Detection | Template matching based object detection |
| 10 | Edge Detection | Canny, Sobel and Prewitt edge detection |
| 11 | Colour Space Conversion | RGB, HSV, YCrCb and Lab conversion |

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and image processing operations
- **Canvas API** – Image display and pixel-level processing
- **PyCharm** – Development environment
- **Python / OpenCV / NumPy** – Image Processing concepts and laboratory reference
